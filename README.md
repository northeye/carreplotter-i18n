# CarReplotter translations

Translations of the user interface of **CarReplotter**, an app that records your drives with an OBD2 adapter
and GPS and replays them on a map.

The app itself is not open source; only the texts of its user interface are published here so that anyone can
help translate them. Pull requests are welcome!

| File | Language |
| --- | --- |
| `en.json` | English (source) |
| `ja.json` | Japanese |
| `de.json` | German |
| `es.json` | Spanish |
| `fr.json` | French |
| `it.json` | Italian |
| `ko.json` | Korean |
| `pt-BR.json` | Portuguese (Brazil) |

Most translations other than English and Japanese were made without a native speaker's review, so
corrections are especially welcome.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to help.
